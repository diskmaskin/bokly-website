Why Bokly

Libraries matter. Bokly opens another local shelf.

No library can hold every title, in every language, exactly when it is needed. Bokly makes useful books already sitting in nearby homes visible and available to borrow.

A different catalogue

Find privately owned textbooks, professional titles, language books and fiction nearby.

Availability you can see

Know whether a copy is available and how far away it is before requesting it.

Access without buying

Borrow a physical book for the time you need it instead of purchasing every title.

Income from an existing shelf

Owners choose what to list and earn when one of their books is borrowed.

How it works

From someone’s shelf to yours.

Bokly handles discovery, the request and payment. The book stays local, so there is no warehouse and no shipping.

01

Find it nearby

Search books available within roughly 5 km.

02

Request it

See the price, send the owner a request and pay securely.

03

Collect and return

Arrange a local handover, read the book and return it on time.

Value on both sides

A marketplace that only works when a real loan happens.

There is no subscription and no book inventory. The borrower sees the full price before requesting. The owner sees their earnings before accepting.

For readers

Another affordable way to access a book that is useful now, without adding it permanently to the shelf.

Find it. Borrow it. Return it.

For book owners

List a book in seconds, control its availability and decide which requests to accept.

Keep the book. Earn when it is used.
Trust and protection

Clear steps. Real people. Support when needed.

Bokly is designed to make local borrowing straightforward for both sides.

01

Verified accounts

Users sign in and verify their phone number before borrowing or approving requests.

02

Secure payment

Payments and lender payouts are handled through Stripe.

03

Clear return period

The 26-day loan period begins only after the physical handover is confirmed.

04

Refunds and support

Declined requests are refunded. Bokly support is available if something goes wrong.
